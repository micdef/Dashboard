# Dashboard

## English

Dashboard is a centralised supervision tool for a small fleet of Linux and Windows servers: heartbeats, inventory, logs, CVE exposure, AI-based anomaly detection and reports, and a fixed catalogue of remote commands.

It is the final project of the AI developer training at Technofutur TIC (2026-2027).

The project is in its design phase. The architecture decisions are recorded in [doc/analyse/adr](doc/analyse/adr/README.md).

## Français

Dashboard est un outil de supervision centralisée pour un petit parc de serveurs Linux et Windows : heartbeats, inventaire, logs, exposition aux CVE, détection d'anomalies et rapports par IA, et un catalogue fixe de commandes à distance.

C'est le projet de fin de la formation Développeur IA de Technofutur TIC (2026-2027).

Le projet est en phase de conception. Les décisions d'architecture sont consignées (en anglais) dans [doc/analyse/adr](doc/analyse/adr/README.md).
